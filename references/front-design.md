# Front Design Rules

## Canvas

Portrait:

```text
1024 × 1536
```

Landscape:

```text
1536 × 1024
```

Orientation must match the original source photograph.

## Fixed visual system

- clean white background
- consistent white margins
- photograph with sharp 90° corners
- no rounded corners
- no outer photo frame
- no drop shadow
- uppercase deep-navy serif city name
- fixed thin warm-gold divider with centered geometric ornament
- smaller uppercase blue local greeting

## City typography

Use an elegant, high-contrast serif with generous tracking.

Suggested color family:

```text
#0B2A55
#123A78
```

If the city name is long, reduce font size rather than compressing the letters.

## Divider

Use the same divider throughout the series:

```text
────── ◇◇ ──────
```

Do not substitute a different flourish, line, or ornament for each postcard.

## Greeting

Use:

- uppercase
- clean sans-serif
- centered alignment
- generous letter spacing
- blue
- clearly smaller than the city name

## Front QA

- [ ] correct orientation
- [ ] correct canvas size
- [ ] sharp photo corners
- [ ] no frame
- [ ] no shadow
- [ ] consistent white margin
- [ ] city correct
- [ ] greeting correct
- [ ] divider matches series
- [ ] typography centered and unclipped
