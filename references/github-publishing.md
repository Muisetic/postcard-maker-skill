- [ ] `SKILL.md` is at the repository root
- [ ] `README.md` renders correctly
- [ ] `LICENSE` reflects non-commercial terms
- [ ] contact email is correct
- [ ] examples can legally be published

## Visual presentation

- [ ] GitHub cover image displays

- [ ] back has exactly 6 postcode boxes
