# Usage Examples

## Single postcard

```text
把这张巴黎照片做成一张明信片，生成正面和背面。
```

## City supplied

```text
这张是在 Porto 拍的，帮我做成明信片。
```

## Batch

```text
把这 8 张旅行照片都做成同一套明信片。每张都保持原来的横竖方向。
```

## Correct an existing back

```text
这张背面的地址线太浅了，稍微加深一点，其他地方不要改。
```

## Correct orientation

```text
这张原来是竖版，改回竖版。正面和背面都要保持 1024×1536。
```

## Greeting override

```text
城市名用 LISBOA，问候语我想写 OLÁ。
```

## Front only

```text
这次先只做正面。
```

## Back only

```text
正面我已经做好了，按照它生成背面。
```
